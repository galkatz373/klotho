# GDK access-controlled workspace

This directory is the public layout for proprietary GDK adapters and
unredacted P1 evidence. The public tree keeps only this file.

Unredacted hardware logs, SDK headers, and holder records are stored here
under licensed SDK access. Public Klotho resolves redacted evidence ids
against this path and fails closed when the bytes are absent. A redacted
id is not public reproduction.

Public CI claim level is P0. A certified or shipped GDK SKU requires P1
hardware evidence and P2 holder acceptance.
