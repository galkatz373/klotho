# Greybox route

KAI-14 eight-Place greybox: a hub, combat pocket, traversal beat, conversation,
cinematic, checkpoint, return shortcut, and optional objective. The plan lives
in `klotho_pattern::greybox_route`. Dressing is content-addressed and
materialized into per-Place placement chunks; runtime only streams the result.

There is no Cargo package or title Rust in this directory. Regeneration keeps
the protected Place anchors. Duplicate source blobs are stored once.
