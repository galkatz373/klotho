# Mini-Tapestry

Mini-Tapestry is the KAI-11 independently shippable increment: one Place, a
ten-minute keep adventure, approved kitbash art/audio, production HUD, three
locales, accessibility settings, credits, checkpoint save, and a desktop
package. There is no Cargo package or title Rust in this directory.

`base.kdown` is the approved keep greybox. `request.ron` is the Distaff request
that instantiates traversal, combat, checkpoint/save, camera, HUD, and
accessibility patterns. Journeys plus `play/critical-path.ron` are the recorded
human critical path. The generic Klotho AI, evaluation, cook, and installer
lane execute the slice.

The increment is retained when Tapestry begins. It is not discarded.
