# Netlock multiplayer/live production track

KAI-24 data-only P0 proving project derived from the bounded Netlock regression.
It selects an approved 32-player shooter service profile and supplies typed
replicated-encounter, matchmaking, reconnect, network/failure matrix, signed
economy/experiment, moderation/privacy, deployment, rollback, incident, and
public-evidence inputs. There is no title Rust in this directory.

The fixture proves only the reproducible public boundary. It is not a claim of
multiplayer or live-service production readiness. Private service, security,
moderation, and scale validation requires signed P1 evidence. Any external
platform or service acceptance requires P2 evidence bound to the same package.
