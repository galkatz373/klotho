# Spindle

Spindle is the KAI-09 data-only proving slice. `base.kdown` is the approved
observatory greybox; `request.ron` is the Distaff request contract; and the
three journey files exercise denial, unlock, and opened states through public
input. The first deterministic model response intentionally binds the passage
to `lockpick_tool`; the trusted journey counterexample drives a bounded repair
to `iron_key` before evidence and Pin.

There is no Cargo package or title Rust in this directory. The generic Klotho
AI, evaluation, and Distaff test harness executes the slice.
