# Tapestry

Tapestry is the KAI-20 data-only vertical route: thirty bounded minutes across
eight Places, assembled through Klotho patterns and the landed production
systems. It carries combat, traversal, an optional quest, compiled Mind,
dialogue, a cinematic, save/resume, localized accessible UI, final approved
asset references, performance measurements, trusted evidence, a recorded human
critical path, and the three desktop package targets.

There is no Cargo package or title Rust in this directory. `base.kdown` and
`request.ron` are authoring inputs; the route, gameplay, bot, and human
recordings use the public input path. `release.ron` binds the review, rights,
budget, and reproduction claims to named evidence rather than treating this
README as proof.

The route remains a proving production, not full title content. Existing slices
are unchanged.
